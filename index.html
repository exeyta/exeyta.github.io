Возможности

Всё для игры собрано в одном окне

Редактор скинов

Собирайте скин по частям прямо в лаунчере: слои, палитра, предпросмотр в 3D. Готовый файл сразу применяется к профилю.

Быстрый запуск

Лаунчер не пересобирает файлы при каждом старте. Повторный запуск игры занимает секунды, а не минуту.

Все версии игры

От старых релизов до свежих снапшотов. Версия переключается одним щелчком, установка идёт в фоне.

Сборки и моды

Forge и Fabric подключаются из интерфейса. Моды и ресурспаки лежат рядом с профилем, а не в дебрях папок.

Профили

Отдельные настройки под каждый сервер или сборку: память, Java, ник. Переключение — без перезапуска лаунчера.

Русский интерфейс

Вопросы

Коротко о главном

Лаунчер платный?

Нет. Скачивание и использование бесплатны, аккаунт Microsoft или Mojang нужен только для входа в игру.

Нужна ли установленная Java?

Нет, лаунчер использует встроенную среду выполнения. Свою Java можно указать в настройках профиля.

Работает ли с модами?

Да. Forge и Fabric подключаются из интерфейса, моды кладутся в папку выбранного профиля.

Куда лаунчер устанавливается?

По умолчанию в профиль пользователя, но папку можно выбрать вручную при установке.

Где сообщить об ошибке?

В issues на GitHub или в Telegram.
