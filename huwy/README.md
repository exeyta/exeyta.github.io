# Huwy Wallet

Игровой кошелёк: валюта **HUWY**, вход только по логину и паролю, переводы по адресу,
трейдинг x2, QR + сканер камеры, админ-выдача, PWA-установка.

**Стек:** только HTML + CSS + JS. Без Node.js, без фреймворков, без сборки.
Библиотеки с CDN: `qrcodejs` (QR), `html5-qrcode` (сканер), `firebase` (Auth + Realtime Database).
Сервер: Firebase проекта `tlpr0d`, база `tlpr0d-default-rtdb` (asia-southeast1).

## Как устроена защита (без своего бэкенда)

- Отправка — один атомарный апдейт: списание + запись перевода + уведомление.
  Правила `database.rules.json` проверяют на сервере, что списание ровно равно
  сумме перевода, — нарисовать деньги нельзя, задвоить отправку нельзя
  (повтор упрётся в уже уменьшенный баланс).
- Забрать чужой перевод нельзя: зачисление требует нетронутую запись
  получателя и одноразовую метку; повторный забор отклоняется.
- Свой баланс можно только уменьшать; увеличить — только через чужой перевод,
  выигрыш x2 или возврат своего незабранного (всё по одному разу).
- Админка — только у UID, вшитого в правила (проверка на сервере, а не в коде).
- Честная оговорка: исход трейдинга решает случай в браузере, приёма живых
  денег нет. Для игры между своими — достаточно.

## Запуск (в консоли Firebase, проект tlpr0d)

1. **Auth:** Authentication → Sign-in method → включи **Email/Password**.
   (Логин превращается в технический `логин@huwy.local`, юзер его не видит.)
2. **Authorized domains:** Authentication → Settings → Authorized domains →
   добавь `exeyta.github.io` (иначе вход с сайта режется).
3. **База:** Realtime Database → выбери базу `tlpr0d-default-rtdb` →
   вкладка **Rules** → вставь целиком `database.rules.json` → Publish.
4. **Админ:** зарегистрируйся на сайте обычным аккаунтом → скопируй его UID
   (Authentication → Users → UID) → вставь в `ADMIN_UID` в `config.js`
   и вместо `ADMIN_UID_PLACEHOLDER` в `database.rules.json` → Publish rules заново.
5. Проверь: регистрация → перевод между двумя аккаунтами → «Забрать»
   у получателя → отмена незабранного → трейдинг → админ-выдача.
