# Huwy Wallet

Игровой кошелёк: валюта **HUWY**, вход только по логину и паролю, переводы по адресу,
трейдинг x2, QR + сканер камеры, админ-выдача, PWA-установка.

**Стек:** только HTML + CSS + JS. Без Node.js, без фреймворков, без сборки.
Библиотеки с CDN: `qrcodejs` (QR), `html5-qrcode` (сканер), `firebase` (Auth + Firestore).
Сервер: Firebase проекта `tlpr0d`.

## Как устроена защита (без своего бэкенда)

- Переводы — эскроу: отправитель списывает себе баланс и создаёт перевод одной
  транзакцией, получатель забирает кнопкой «Забрать». Правила `firestore.rules`
  запрещают увеличить свой баланс любым другим путём и запрещают потратить один
  перевод дважды.
- Баланс чужого кошелька прочитать/изменить нельзя (только свой + справочники
  адресов для поиска получателя).
- Админка — только у UID, вшитого в `firestore.rules` (проверка на сервере правил,
  а не в коде сайта).
- Честная оговорка: исход трейдинга решает случай в браузере, приёма реальных
  денег нет (ЮMoney удалён). Для игры между своими — достаточно; для настоящих
  денег нужен свой сервер с вебхуками платёжной системы.

## Запуск (5 шагов в консоли Firebase)

Проект `tlpr0d` уже создан, ключ уже вшит в `config.js`.

1. **Auth:** Authentication → Sign-in method → включи провайдер **Email/Password**.
   (Логин превращается в технический `логин@huwy.local`, юзер его не видит.)
2. **База:** Firestore Database → Create database → Production mode → регион
   ближе к игрокам (например `eur3`).
3. **Правила:** Firestore Database → Rules → вставь целиком `firestore.rules` → Publish.
4. **Админ:** зарегистрируйся на сайте обычным аккаунтом → скопируй его UID
   (Authentication → Users → UID) → вставь в `ADMIN_UID` в `config.js`
   и вместо `ADMIN_UID_PLACEHOLDER` в `firestore.rules` → Publish rules заново.
5. Залей на хостинг (ниже) и проверь: регистрация → перевод между двумя
   аккаунтами → «Забрать» у получателя → трейдинг → админ-выдача.
